This is a toy driver for Intel's E1000 NIC. Requirements were generated by ChatGPT, othervise AI has not been used 
at all, mainly because this is a project for fun and AI coding is no fun at all. ALl info is found in the docs, web
or in the datasheet (can be found in `data/` directory).

This project has to be built in kernel's source tree under `drivers/net/ethernet/janis` directory. There are also
some requirements in:
1) `drivers/net/ethernet/Makefile`:
    add the following line: `obj-$(CONFIG_NET_VENDOR_JANIS) += janis/`
2) `drivers/net/ethernet/Kconfig`:
    add the following line: `source "drivers/net/ethernet/janis/Kconfig"`
